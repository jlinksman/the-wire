# V1.md — The build

## What to build
One private web page, rebuilt every 15 minutes from about 20 sources, that works on my iPhone and my desktop.

### 1. The feed
- Every item from every source with `enabled: true` in `sources.yaml`, newest first.
- Each row: time (relative, like "12m," with the exact time on tap), desk tag, source name, headline. Tap to expand: the feed's own short description and a link out.
- Desk filter buttons: ALL, BEACON, GOV, LAW, WORLD.
- Watchlist matches (from `sources.yaml`) are visibly highlighted.
- Keep about 7 days of items. Drop exact duplicates (same link). Don't attempt cross-outlet story grouping.
- Google News results: filter out the junk domains listed in that source's `exclude_domains`.

### 2. "Since you last opened"
- A divider line marks where my previous visit ended. Store the last-visit time in the browser (localStorage), so it works per device. Wrap storage in try/catch so the page still works without it.
- A count at the top: "24 new since 7:42 AM."

### 3. Breaking strip (top of the page)
- **Live player:** a compact embedded YouTube player showing one 24/7 news channel, with buttons to switch among the channels marked `enabled: true` under `video_youtube` in `sources.yaml`. Use YouTube's channel live embed (`https://www.youtube.com/embed/live_stream?channel=CHANNEL_ID`). If that embed fails for a channel, show a "Watch live" link to `https://www.youtube.com/channel/CHANNEL_ID/live` instead. The player starts collapsed and loads only when I tap it, so the page stays fast.
- **Last hour:** the items published in the last 60 minutes, from sources marked `fast: true`, as a short list.
- **Weather alert banner:** when the National Weather Service has an active alert for Beacon, show it in a red banner with a link.

### 4. Footer
- "As of" time of the last successful build.
- Source health: each source's last success, item count, and last error. Stale or failing sources in red.

## Not in V1
No quotes extraction, PDF parsing, story grouping, ranking, push alerts, email, translation, API keys, accounts beyond GitHub and Cloudflare, or anything else in ROADMAP.md.

## Done when
- [ ] The page loads on my iPhone over cellular, behind Cloudflare Access, and refuses anyone but my email.
- [ ] The workflow runs on schedule for 72 hours, and the page's "as of" time is never more than 45 minutes old.
- [ ] Every enabled source shows in source health. A deliberately broken URL shows as failing without breaking the build.
- [ ] The "since you last opened" divider and new-item count work on my phone.
- [ ] The live player plays at least two of the channel presets, or falls back to a working link.
- [ ] Watchlist terms highlight correctly (test with a known headline).
- [ ] The repository contains no fetched content and no secrets.
- [ ] Usage stays well under every free-tier limit (report the numbers).
- [ ] Add it to my iPhone home screen and confirm it opens like an app.
